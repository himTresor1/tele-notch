Install

  1. Download TeleNotch.zip, open it, and drag TeleNotch into Applications.
  2. Open it. A short guide sets up your Anthropic API key and permissions.
  3. That's it. TeleNotch updates itself from then on.

Early builds aren't notarized by Apple yet. If macOS won't open TeleNotch, go to System Settings → Privacy & Security and click Open Anyway.
